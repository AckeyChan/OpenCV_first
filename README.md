# OpenCV 图像处理实验

## Task 1

### 1. 实验说明

使用 OpenCV 对 `resources/sample.jpg` 完成读图、灰度化、HSV 分离、滤波、红色提取、形态学处理、外轮廓筛选、绘制、旋转和裁剪。输入图像尺寸为 `6000 x 4000`，结果保存到 `result/task1_images/`。

### 2. 编译运行

```bash
cmake -S . -B build
cmake --build build
cd build
./OpenCV_first
```

程序会检查图像是否读取成功；读取失败时输出错误信息并退出。正常运行后输出 16 张图和 `contour_areas.txt`。

### 3. 参数

#### 读图与颜色转换

- 输入：`../resources/sample.jpg`
- 灰度：`COLOR_BGR2GRAY`
- HSV：`COLOR_BGR2HSV`
- H 范围：`0--179`；S、V 范围：`0--255`

#### 滤波

- 均值滤波：`blur`，核 `5 x 5`
- 高斯滤波：`GaussianBlur`，核 `5 x 5`，`sigma = 1.5`
- 中值滤波：`medianBlur`，核尺寸 `5`

#### 红色掩膜

采用 HSV 双区间阈值，并将两个掩膜按位或：

- 低色相区间：`H=[0,10]`，`S=[100,255]`，`V=[100,255]`
- 高色相区间：`H=[160,179]`，`S=[100,255]`，`V=[100,255]`
- 代码：`redMask = lowRedMask | highRedMask`

#### 形态学与轮廓

- 结构元素：椭圆形 `MORPH_ELLIPSE`
- 核尺寸：`5 x 5`
- 输出：腐蚀、膨胀、开运算、闭运算
- 轮廓：对闭运算结果使用 `RETR_EXTERNAL` 和 `CHAIN_APPROX_SIMPLE`
- 面积条件：`5000 px < area < 10000000 px`
- 外接矩形宽高比：`0.2 <= width / height <= 5.0`
- 轮廓颜色：红色；外接矩形颜色：绿色


#### 绘制与变换

- 圆：圆心为图像中心，半径为 `min(width, height) / 5`
- 矩形：左上角为 `(width / 10, height / 10)`，尺寸为 `width / 3 x height / 3`
- 文字：`OpenCV`，`FONT_HERSHEY_SIMPLEX`，字号 `1.5`，线宽 `3`
- 旋转：绕图像中心旋转 `35` 度
- 裁剪：原图左上角区域，宽高各取一半

## Task 2：合成旋转视频参数拟合

### 1. 方法与参数

输入视频为 `resources/task_2.mp4`，视频参数为 `960 x 720`、`60 FPS`、`24 s`、`1440` 帧。使用已知旋转中心 `(480, 360)` 和半径 `220 px`，在 HSV 中提取青色目标（`H=[75,105]`、`S=[80,255]`、`V=[80,255]`），取最大青色连通区域质心作为目标位置。

按题目定义计算角度：

```text
theta = atan2(center_y - target_y, target_x - center_x)
```

随后按相邻帧展开角度，并以第 0 帧为时间原点，直接拟合：

```text
omega(t) = b + A sin(Omega t + phi)
theta(t) = theta0 + b*t + A/Omega * (cos(phi) - cos(Omega*t + phi))
```

先对 `Omega` 做 `0.149--5.0 rad/s` 的频率网格搜索，线性求解初值，再使用 Ceres 优化 `A、b、Omega、phi、theta0`。约束为 `A >= 0`、`b >= 0`、`0.001 <= Omega <= 10`，相位统一到 `[-pi, pi)`。

### 2. 输出与报告

结果保存到 `result/task2_fit/`：

- `task2_fit_result.md`：模型、A、b、Omega、phi、theta0、周期、角度 RMSE、有效样本数、帧范围、方法和 Ceres 状态
- `angle_fit.csv`：帧号、时间、目标坐标、观测角度、拟合角度、角度残差和拟合角速度
- `tracking_overlay.mp4`：标出旋转中心、青色目标和识别参数的视频
- `fit_comparison.png`：观测角度与拟合角度对比图
- `angular_velocity.png`：估计角速度曲线
- `residuals.png`：角度残差曲线

当前运行结果：有效样本 `1440`，帧范围 `0--1439`，角度 RMSE `0.00234146 rad`，Ceres 优化收敛。

## Task 3 / Task 4：真实能量机关识别与稳定跟踪

本任务处理两个真实能量机关视频，不要求参数拟合。`task_3.mp4` 与 `task_4.mp4` 使用同一个处理函数，只有“同时跟踪的目标数上限”不同。

### 1. 场景对应关系与实际视频参数

| 视频文件 | 场景 | 同时亮起目标上限 | 传入上限 | 分辨率 | 帧率 | 总帧数 | 时长 |
|---|---|---|---:|---|---:|---:|---:|
| `resources/task_3.mp4` | 小能量机关 | 1 | `1` | `1440 x 1080` | `30 FPS` | `796` | 约 `26.53 s` |
| `resources/task_4.mp4` | 大能量机关 | 2 | `2` | `1440 x 1080` | `30 FPS` | `1800` | `60 s` |

真实录像没有可靠的逐帧现场采集时间，播放时间不能当作现场运动时间，因此本任务只做视觉识别与稳定跟踪，不做运动参数拟合。输出文件名与所在目录见第 7 节。

### 2. 识别与可视化

识别流程：

- 每帧由 BGR 转换到 HSV，用橙色发光区域阈值提取候选：`H=[5,35]`、`S=[37,255]`、`V=[40,255]`。
- 用 `3 x 3` 椭圆核做闭运算，连接同一扇叶被打断的发光线段。
- 对掩膜提取外轮廓（`RETR_EXTERNAL`），并做以下过滤：
  - 轮廓面积 `>= 1 px`
  - 外接矩形边长在 `20--300 px` 之间
  - 最小外接圆半径在 `12--180 px` 之间
  - 面积 `>= 100 px` 时，圆度 `4*pi*area/perimeter^2 >= 0.30`，用于排除细长或破碎的噪声
- 每个候选统计其最小外接圆内部的 mask 像素总数，作为该候选的面积度量。
- 按最小外接圆半径把候选分成两类：
  - 半径 `>= 35 px`：扇叶（被选目标）
  - 半径 `10--18 px`：R 标中心候选

每帧在原画面上叠加以下可视化元素：

| 元素 | 画法 |
|---|---|
| R 标中心 | 白色圆圈加十字准线 |
| 被选目标扇叶圆轮廓 | 绿色圆圈 |
| 扇叶圆中心 | 绿色小圆点 |
| 两中心连线 | 白色直线 |
| 目标 ID 与跟踪状态 | 绿色文字 `ID n detected/lost` |

### 3. 跟随中心变化

- R 标中心不使用固定图像坐标，而是每帧从当前帧的 R 标中心候选中重新确定。
- 对每个跟踪目标，在 `450 px` 范围内选择一个 R 标中心候选：优先取与该扇叶距离**较远**的候选。原因是扇叶自身结构中也存在小圆，距离很近的候选属于扇叶本身，连线另一端的圆才是 R 标中心。
- 连线与相对位置（角度）都以**当前帧检测到的中心**为原点：

```text
theta = atan2(center_y - target_y, target_x - center_x)
```

  因此当画面晃动、中心发生移动时，目标相对中心的位置随之更新，不会因为使用固定坐标而产生偏差。
- 本任务不拟合角速度与角加速度等运动参数。

### 4. 稳定锁定与身份保持

- 目标 ID 由跟踪状态机分配并保存在 `tracks` 列表中，**不依赖每帧轮廓列表的顺序**；因此同一目标在相邻帧即使检测顺序变化，ID 也不会改变。
- 首次出现有效目标时创建一个 ID；小能量机关最多 1 个、大能量机关最多 2 个跟踪槽位。
- 已激活的目标优先与当前帧候选关联：
  - 状态为 `detected` 时，用“上一帧位置 + 平滑后的速度”预测下一位置，再取距离最近的候选，关联范围 `50 px`。
  - 只有未被占用的候选才可能分配新 ID。
- 因此当另一个目标（例如大能量机关的第二个扇叶）出现时，只要原目标持续有效可见，就会继续占用原槽位并保持原 ID，不会被新目标抢走身份。
- 速度采用加权平滑更新：当前位移 `0.35`、历史速度 `0.65`，降低画面晃动造成的速度突变。

### 5. 丢失与重选

- 判定为丢失的情况有两种：
  - 当前帧没有落在关联范围内的候选；
  - 关联到的扇叶候选区域 mask 像素总数小于 `1500 px`（目标基本熄灭或大面积被遮挡）。
- 进入丢失后**保留原 ID**，并标记为 `lost`，不会立即删除轨迹。
- `lost` 状态下不再使用速度外推，而是固定在最后可靠位置搜索；在**当前帧内**最多尝试 `5` 次，搜索范围依次为 `50 / 65 / 80 / 95 / 110 px`，一旦找到候选立即使用，当前帧找不到则保持原位置继续等待。
- 丢失容忍帧数为 `5` 帧：连续丢失超过 `5` 帧后释放该跟踪槽位，轨迹标记为不激活。
- 重选条件：槽位被释放后，未被占用的有效候选（mask 面积 `>= 1500 px`）可以复用该槽位并获得新的 ID。
- 典型重选情况：原目标熄灭或长时间被遮挡 → 连续 `5` 帧无有效观测 → 槽位释放并停止绘制 → 之后有扇叶重新亮起 → 该候选获得新 ID 并重新建立跟踪。
- 正常重选只发生在轨迹释放之后，属于有依据的重建；程序不会用“每帧重新初始化”的方式规避身份保持要求。

### 6. 跟踪状态展示

结果视频中每个目标都显示 `ID` 与状态：

| 状态 | 触发条件 | 画面表现 |
|---|---|---|
| `detected` | 本帧成功关联到满足面积要求的扇叶候选（`missedFrames == 0`） | 绘制扇叶圆、圆心、R 标中心与连线，文字显示 `detected` |
| `lost` | 保留 ID 但本帧无有效观测（`missedFrames > 0`） | 位置停留在最后可靠位置，文字显示 `lost` |

### 7. 输出文件

两个视频都输出完整帧序列（`task_3` 共 `796` 帧，`task_4` 共 `1800` 帧，帧率与输入一致），输出目录为 `result/task3_windmill/task_3/` 和 `result/task3_windmill/task_4/`：

| 文件 | 说明 |
|---|---|
| `tracking_overlay.mp4` | 叠加 R 标中心、扇叶圆轮廓、扇叶圆心、两中心连线、目标 ID 和跟踪状态的跟踪结果视频 |
| `mask_video.mp4` | 独立生成的黑白掩膜视频，输出前用 `3 x 3` 椭圆核膨胀一次，便于检查识别质量 |
| `mask_6s.png` | 视频第 6 秒的检测掩膜（闭运算后、未膨胀） |
